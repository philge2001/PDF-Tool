# Sicherheit

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über
GitHub: *Security → Report a vulnerability* in diesem Repository.

Hilfreich sind:
- eine kurze Beschreibung und die betroffene Funktion (z. B. Öffnen, Signaturen prüfen, Schwärzen),
- wenn möglich eine Beispiel-PDF oder Schritte zum Nachstellen,
- Betriebssystem und Version bzw. Commit.

Du bekommst in der Regel innerhalb von zwei Wochen eine Rückmeldung.

## Hinweise

- PDF Tool führt kein JavaScript aus PDF-Dateien aus.
- Passwörter für geschützte PDFs und digitale IDs werden nur im Arbeitsspeicher gehalten und
  nicht gespeichert.
- Berechtigungen geschützter PDFs (Drucken, Kopieren …) sind eine Vorgabe für PDF-Programme,
  kein kryptografischer Schutz.
